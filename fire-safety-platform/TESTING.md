### ✅ الطقس | Weather Page

#### الوصول

1. ✅ تسجيل الدخول
2. ✅ الضغط على "الطقس" في القائمة
3. ✅ التحقق من عرض `/weather`

#### التحقق من البيانات

1. ✅ يجب عرض درجة الحرارة (رقم + °)
2. ✅ يجب عرض سرعة الرياح (رقم + كم/س)
3. ✅ يجب عرض اتجاه الرياح (N, NE, E, إلخ)
4. ✅ يجب عرض درجة الاتجاه (0-360°)
5. ✅ تحديث الصفحة → البيانات يجب أن تُحمّل مرة أخرى

#### التصميم

1. ✅ الخلفية زرقاء متدرجة
2. ✅ 3 بطاقات (حرارة، سرعة، اتجاه)
3. ✅ الرموز التعبيرية موجودة (🌡️ 💨 🧭)
4. ✅ تحذير الرياح القوية موجود
5. ✅ النص بالعربية ومحاذاة RTL

### ✅ الخريطة | Map Page

#### الوصول

1. ✅ الضغط على "الخريطة" في القائمة
2. ✅ التحقق من عرض `/map`

#### عرض الخريطة

1. ✅ خريطة OpenStreetMap معروضة
2. ✅ مركزة على إفران
3. ✅ علامات (markers) موجودة على الخريطة

#### المؤشرات (Markers)

1. ✅ المؤشر الأحمر = قيد الانتظار
2. ✅ المؤشر البرتقالي = قيد التنفيذ
3. ✅ المؤشر الأخضر = مكتمل
4. ✅ الضغط على المؤشر → popup يظهر

#### Popup Details

يجب أن يحتوي على:
1. ✅ عنوان "حادث حريق"
2. ✅ الحالة مع لون الخلفية
3. ✅ الشدة (1-5)
4. ✅ السبب
5. ✅ التاريخ
6. ✅ الوصف (إن وجد)

#### الأسطورة (Legend)

1. ✅ 3 نقاط ملونة معروضة
2. ✅ النصوص: "قيد الانتظار"، "قيد التنفيذ"، "مكتمل"

## 🚀 الاختبار التلقائي | Automated Testing (للمستقبل)

### إطار العمل الموصى به

```bash
# Jest + React Testing Library
npm install --save-dev @testing-library/react @testing-library/jest-dom jest

# Playwright for E2E
npm install --save-dev @playwright/test

# Cypress alternative
npm install --save-dev cypress
```

### مثال على اختبار الوحدة

```javascript
// __tests__/WeatherDisplay.test.tsx
import { render, screen } from '@testing-library/react';
import WeatherDisplay from '@/components/weather/WeatherDisplay';

test('يعرض درجة الحرارة', async () => {
  render(<WeatherDisplay />);
  const temp = await screen.findByText(/°/);
  expect(temp).toBeInTheDocument();
});
```
